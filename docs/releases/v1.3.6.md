# Operation Steel Tide v1.3.6

This release makes extraction multiplayer host-authoritative, improves AI movement and inventory ergonomics, replaces the Desert Eagle placeholder with a licensed authored model, and removes recurring HUD frame allocations.

## Multiplayer World Synchronization

- Creating a room now keeps the host in the deployment lobby until another player joins and the host selects `START OPERATION`.
- Every peer loads the host-selected map from the same seed while gameplay remains paused.
- The host sends reliable initial snapshots for enemies, AI squadmates, objectives, reinforcements, extraction, loot sources, player down/revive state, and the final outcome before releasing the match.
- Clients send player movement and requested actions to the host instead of simulating an independent mission world.
- Late joins are rejected after launch, stale LAN rooms expire, and disconnected human slots return to AI control.

## Gameplay And Presentation

- AI squadmates recover more reliably on residential stairs and narrow multi-floor routes.
- Picking up a compatible firearm automatically fills the first empty primary, secondary, or sidearm slot.
- The Desert Eagle now uses ELIZION's CC BY 4.0 authored model with corrected first-person and inventory-preview framing.
- HUD health, armor, stamina, ammunition, equipment, medical, quick-slot, and compass presentation now skips unchanged values.
- Weapon HUD views no longer clone all weapon builds every frame, and medical inventory counts are collected in one pass.
- The Godot GPU profiler timestamp capacity is raised to avoid overflow during long profiling sessions.

## Verification

The project builds with zero warnings and zero errors. The HUD performance diagnostic completes 20,000 stable updates with 24 bytes allocated, no Gen0/Gen1/Gen2 collections, and no redundant presentation updates.

The following Godot diagnostics pass: `--validate-hud-performance`, `--validate-quick-slots`, `--validate-tactical-hud`, `--validate-medical`, `--validate-weapon-ui`, `--validate-backpack-tab`, `--validate-loot`, `--validate-stamina`, `--validate-performance`, `--validate-crowd-performance`, and `--validate-squad-performance`.

A 38-operator stress run averages 16.6 ms with no slow frames, while the close-squad test averages 16.5 ms with no over-budget frames. A 12-minute 49-second graphics-profiler session did not reproduce a multi-second freeze; steady-state GPU usage averaged about 9.1% and dedicated video memory stayed near 942 MB on the validation machine.
