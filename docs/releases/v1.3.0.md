# Operation Steel Tide v1.3.0

This feature release adds the standalone TIDEFORGE demolition match, expands its tactical AI, and upgrades the extraction presentation while preserving the existing extraction progression and co-op flow.

## Highlights

- MR12 5v5 demolition with first-to-13 scoring, halftime side swaps, win-by-two overtime, physical planting and defusing, and isolated match wallets.
- A 15-second purchase phase before every round with exact prices for pistols, primary weapons, armor, and frag grenades. The opening $800 can buy a sidearm but cannot buy a primary weapon.
- A twelve-map briefing carousel with TIDEFORGE ARENA playable and the remaining map slots visibly locked until their geometry ships.
- Combat-first AI arbitration, clock-pressure decisions, shared sighting intelligence, route detours, site rotations, retakes, cover duties, and teammate plant/defuse handoff when the player cannot complete the objective.
- A Blender-authored rescue tilt-rotor, exterior extraction chase camera, animated ocean backdrop, improved tactical materials, and corrected optic alignment during traversal.
- Scene-authored pause, demolition briefing, and round-purchase interfaces backed by deterministic diagnostics and the repository engineering standards.

## Run On Windows

1. Download `OperationSteelTide-1.3.0-windows-x64.zip` and optionally its `.sha256` file.
2. Extract the complete ZIP to a writable folder.
3. Run `PLAY.bat`.

The package contains the exported Godot client, required .NET runtime files, and the local Go mission/progression service. See `ONLINE_PLAY.md` in the package for internet and private-network connection options.

The release is a portable ZIP with no installer and does not request administrator access. It is not code-signed, so Windows SmartScreen may show an unknown-publisher warning.

## Known Prototype Limits

- TIDEFORGE ARENA is the only currently playable demolition map; the other eleven carousel entries are explicit locked placeholders.
- Online co-op remains player-hosted ENet without matchmaking or a dedicated gameplay server.
- Character animation and parts of the environment remain programmer art and will continue to be replaced incrementally.
