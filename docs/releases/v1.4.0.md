# Operation Steel Tide v1.4.0

This release moves Operation Steel Tide into Jianghai Old City, sharpens the public project presentation, corrects first- and third-person weapon handling, and adds verified Windows and universal macOS packages.

## Jianghai Old City

- The operation now presents Jianghai Old City and the Tideglass Reactor as its central setting and objective.
- The project cover and squad gallery have been replaced with cinematic key art built specifically around the new setting.
- English and Chinese README pages now use a focused full-width presentation instead of the old black arsenal, inventory, and medical-wheel panels.
- Current in-engine captures remain available as clearly labeled links for readers who want an exact gameplay view.

## Weapon Presentation

- First-person handgun, SMG, rifle, and precision-weapon poses now align authored hands to family-specific primary and support grips.
- Pistol support hands no longer float beside the weapon, and rifle arms no longer rotate into vertically flipped poses.
- Third-person rifle carry poses, SMG scale, and SMG weapon audio have been corrected and validated across the operator roster.
- Procedural safe wheel ownership has been corrected so exported builds shut down cleanly without a native heap crash.

## Packages

- Windows x64: `OperationSteelTide-1.4.0-windows-x64.zip`
- macOS universal (Apple Silicon and Intel): `OperationSteelTide-1.4.0-macos-universal.zip`

The macOS application is currently unsigned and not notarized. Depending on local Gatekeeper settings, players may need to approve the application manually or sign it locally before first launch.

## Verification

- `dotnet build OperationSteelTide.csproj` completes with zero warnings and zero errors.
- `--validate-large-map`, `--validate-combat-models`, `--validate-hand-diagnostics`, `--validate-operator-carry`, and `--validate-weapon-audio` all pass.
- The final Windows archive was extracted and its exported executable passed clean-shutdown, weapon-audio, and operator-carry smoke tests with exit code 0 and no error, fatal, or crash log entries.
- Both archives were audited for their required runtime payloads and for the absence of validation or promotional capture files.
- The macOS archive contains separate Apple Silicon and Intel .NET runtimes and a two-architecture universal executable. Its runtime launch cannot be tested on the Windows packaging host.
