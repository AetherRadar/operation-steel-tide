# Operation Steel Tide v1.3.4

This release adds automatic LAN room discovery for extraction and demolition sessions while preserving manual IP and tunnel connections.

## Multiplayer Improvements

- `JOIN GAME` now lists compatible hosts found on the same Wi-Fi or wired LAN.
- Selecting a room fills the host endpoint, switches to join mode, and selects the host's map.
- Hosts advertise their game mode, map, player count, capacity, gameplay port, and exact game version.
- Room advertisements continue while the host is playing and expire automatically after the host disappears.
- Full rooms are visible but cannot be selected, and incompatible game versions are ignored.
- Manual `host:port` entry remains available when broadcast discovery is blocked.
- Gameplay uses UDP `28960`; LAN discovery uses UDP `28961`.

## Verification

The source passes `dotnet build OperationSteelTide.csproj` with zero warnings and zero errors. The following Godot diagnostics pass: `--validate-lan-discovery`, `--validate-network-endpoint`, `--validate-operations-office`, `--validate-demolition-briefing`, `--validate-demolition`, and `--validate-squad`.

Both lobby layouts were captured in join mode with a discovered room and visually checked for clipping or overlapping controls.
