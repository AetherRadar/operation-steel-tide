# Operation Steel Tide v1.2.1

This patch release adds the project icon to the Windows executable, trims diagnostic and development-only files from the exported PCK, and corrects the packaged online-play and armor-plating documentation. Gameplay behavior is unchanged from v1.2.0.

## Run on Windows

1. Download `OperationSteelTide-1.2.1-windows-x64.zip` and optionally its `.sha256` file.
2. Extract the complete ZIP to a writable folder.
3. Run `PLAY.bat`.

The package contains the exported Godot client, required .NET runtime files, and the local Go mission/progression service. See `ONLINE_PLAY.md` in the package for internet and private-network connection options.

For the complete feature overview and known prototype limits, see the [v1.2.0 milestone notes](v1.2.0.md).
