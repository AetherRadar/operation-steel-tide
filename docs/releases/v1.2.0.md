# Operation Steel Tide v1.2.0

This is the first packaged Windows build of the prototype. It is a playable systems-first milestone, not a production-ready game or architecture reference.

## Highlights

- Complete deployment, objective, looting, reinforcement, and extraction loop in one 340 m x 320 m harbor district.
- Three-operator squads with Assault, Medic, and Recon roles; AI teammates fight, follow orders, use class abilities, and revive downed operators.
- Solo play, ENet listen-server co-op, public `host:port` joining, and AI replacement when a peer disconnects.
- Persistent loadouts and extraction value, six firearms, attachments, ammunition grades, medical supplies, armor, backpacks, and world drops.
- Eleven accessible residential towers, rooftop routes, exterior fire escapes, and 22 walkable glass skybridges.
- Drivable service vehicles, rival extraction squads, a roaming Boss, and an optional local Go mission/progression service.

## Run on Windows

1. Download `OperationSteelTide-1.2.0-windows-x64.zip` and optionally its `.sha256` file.
2. Extract the ZIP to a writable folder.
3. Run `PLAY.bat`.

The package contains the exported Godot client, required .NET runtime files, and the local Go service. Windows Firewall may ask for access when hosting a co-op session. See `ONLINE_PLAY.md` in the package for internet and private-network connection options.

## Known Prototype Limits

- Visuals and animation are programmer art and remain rough.
- The current interface and much of the world are composed in C#; the major authored UI screens are being migrated incrementally to reusable Godot scenes without changing gameplay.
- Online co-op uses a player-hosted listen server. There is no dedicated headless gameplay server, matchmaking, or relay service included.
- The current release contains one playable map. The other operation slots shown in the deployment interface are locked placeholders.

Bug reports and focused playtest feedback belong in [GitHub Issues](https://github.com/AetherRadar/operation-steel-tide/issues). The architecture tradeoffs and planned boundaries are documented in [ARCHITECTURE.md](https://github.com/AetherRadar/operation-steel-tide/blob/main/ARCHITECTURE.md).
