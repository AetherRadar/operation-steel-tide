# Operation Steel Tide v1.3.3

This patch release fixes the multiplayer deployment address control and makes optional host binding functional in both extraction and demolition sessions.

## Multiplayer Fixes

- `HOST GAME` address fields are editable instead of appearing disabled.
- A blank host address listens on all network interfaces at UDP port `28960`.
- Hosts can enter a local bind IP or `IP:PORT` for a specific network interface or port.
- Invalid host bind addresses are rejected in the lobby without spending deployment credits.
- `JOIN GAME` keeps its existing host/IP validation and connection-gated deployment behavior.

## Verification

The source passes `dotnet build OperationSteelTide.csproj` with zero warnings and zero errors. The following Godot diagnostics pass: `--validate-network-endpoint`, `--validate-demolition-briefing`, `--validate-demolition`, and `--validate-squad`.
