# Opening combat theme

`steel_tide_opening_combat.wav` is an original project-authored procedural
composition generated by `scripts/audio/build_opening_combat_theme.py`.

- 30-second seamless tactical loop
- 44.1 kHz, 16-bit stereo PCM
- 128 BPM, D minor
- No third-party samples or recordings

The track is intentionally mixed below the firearm bus so the game's recorded
weapon reports remain the foreground sound during combat.
