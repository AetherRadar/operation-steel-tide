# Kenney City Kit Roads selection

This directory contains selected authored street furniture used by the Tideglass Reactor demolition arena.

- Creator: Kenney
- Official source: https://kenney.nl/assets/city-kit-roads
- Official download: https://kenney.nl/media/pages/assets/city-kit-roads/74288c9459-1787042796/kenney_city-kit-roads.zip
- Acquired: 2026-08-27
- License: Creative Commons Zero 1.0 Universal (CC0 1.0)
- Attribution: Not required; creator credit is retained as a courtesy
- License evidence: `KENNEY_LICENSE.txt`
- Package evidence: `PACK_PREVIEW.png` from the official archive

The local selection contains twenty GLBs:

- Construction dressing: `construction-barrier.glb`, `construction-cone.glb`, `construction-fence.glb`, and `construction-light.glb`
- Street furniture: `dumpster.glb`, `electricity-pole-wide.glb`, `light-curved.glb`, `light-square-double.glb`, `road-sign-stop.glb`, `road-sign-warning.glb`, `traffic-light.glb`, and `traffic-light-hanging.glb`
- Road surfaces: `road-bend.glb`, `road-crossing.glb`, `road-crossroad.glb`, `road-driveway-double.glb`, `road-intersection.glb`, `road-side.glb`, `road-square.glb`, and `road-straight.glb`

Their original shared material atlas is retained as `Textures/colormap.png`. The files were copied from the official GLB package without geometry or texture modification.
