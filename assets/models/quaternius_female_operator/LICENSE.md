# Quaternius Female Field Operator

The female field-operator model is adapted from **Soldier**, included in the
**Ultimate Modular Women** pack by Quaternius (`@Quaternius`).

- Creator: Quaternius
- Official source: https://quaternius.com/packs/ultimatemodularwomen.html
- Exact license: CC0 1.0 Universal / Public Domain Dedication
- License text: https://creativecommons.org/publicdomain/zero/1.0/
- Acquisition date: 2026-08-27
- Attribution requirement: none; creator credit is retained as a courtesy

The runtime file `quaternius_female_operator.glb` is rebuilt in Blender from
the tracked source model. Its 25 locomotion, combat, incapacitation, and revive
actions are retargeted from the separately tracked Quaternius Universal
Animation Library sources, which are also CC0 1.0 Universal.

Source and processing map:

- Original downloaded model: `source_art/third_party/quaternius_modular_women/Soldier.blend`
- Pack license copy: `source_art/third_party/quaternius_modular_women/LICENSE.txt`
- Retargeted editable source: `source_art/third_party/quaternius_modular_women/quaternius_female_soldier_animated.blend`
- Reproducible Blender build: `scripts/blender/build_quaternius_female_operator.py`
- Runtime export: `assets/models/quaternius_female_operator/quaternius_female_operator.glb`

The downloaded pack license file labels itself “Ultimate Modular Males,” but
the official Ultimate Modular Women page identifies the women pack as CC0 and
links the downloaded source folder. This apparent pack-template typo is kept
unchanged in the evidence copy.
