# Jianghai Old City License Evidence

This record identifies the external assets used in the authoritative Jianghai
Old City DCC scene and preserves one evaluated source that was not selected
for delivery.
The existing Poly Haven models and surface sets reused by this scene were
acquired on 2026-08-06. Initial map-specific source files were acquired on
2026-08-27; five additional delivered BlenderKit assets and eight finished
Poly Haven 1K glTF assets were acquired on 2026-08-28. Official source pages
were rechecked on 2026-08-28. Cache paths below are relative to
`JIANGHAI_ACQUISITION_ROOT`; paths beginning with `assets/` are
repository-local sources that predate this map composition.

## Runtime and editable mapping

The authoritative editable source is:

- `source_art/world/jianghai_old_city/jianghai_old_city.blend`

Composition, modeling, material, lighting, and sign changes are made directly
in that packed Blender scene. The export-only script
`scripts/blender/export_jianghai_old_city.py` validates and exports it to:

- `assets/models/jianghai_old_city/jianghai_old_city.glb`
- `assets/models/jianghai_old_city/rollershutter_window_03.glb`

The export policy caps the longest runtime-texture dimension at 1024 pixels
and recompresses eligible high-resolution runtime images as JPEG quality 90
before packing. The two visible objective-terminal bodies combine the CC0
Utility Box 01 and Television 02 sources; their small status screens and
adaptation work are project-authored in the authoritative `.blend`.

The export script does not reconstruct the map from acquisition-cache files.
No script reconstructs the complete map. The packed `.blend` remains the sole
authoritative source for the final hand-edited composition.

The eight Poly Haven bundles acquired on 2026-08-28 remain in the external
cache as 1K glTF, `.bin`, and texture sidecars. Their adapted geometry,
materials, and textures are packed into the authoritative `.blend` and then
exported inside the runtime GLB; the repository does not need the external raw
bundles to reproduce an export of the saved scene. All eight are CC0, so no
non-redistributable marketplace payload is present in the delivered files.

The Modular Urban Apartments Facade cache bundle is retained outside the
repository as evaluation evidence only. Neither the authoritative `.blend` nor
the runtime GLB contains its geometry, materials, textures, or images. The GLB
may retain an `evaluated_not_used` provenance field naming the evaluation;
that string is an audit record, not an embedded asset payload.

The original Noto font is likewise absent from both final files. Only the
converted static Chinese glyph meshes remain. The export script rejects any
non-built-in Blender font datablock before packing or exporting.

### Delivery exclusion audit

A read-only audit on 2026-08-28 opened the authoritative `.blend` in Blender
4.5 and found zero font datablocks and zero apartment-named objects,
materials, or images. Inspection of the exported GLB JSON found zero
apartment nodes, meshes, materials, or images and zero Noto-named entries.

The same audit recorded seven required runtime anchors:
`AuthoredStreetNetwork`, `JianghaiTenementDistrict`,
`RedStarElectronicsFactory`, `GuangchangPawnshop`, `OldCityMarketBridge`,
`GrandHotelSecurityTerminalVisual`, and
`MunicipalTreasuryManifestTerminalVisual`. In the final saved DCC scene, the
Municipal terminal root's duplicate 180-degree rotation is removed and its
screen faces opposite the Grand terminal. All 22 Rollershutter Window 03 and
Exterior Aircon Unit instances are placed flush against tenement facades;
none remains in `CentralAvenue`. Final DCC QA deletes the redundant
`JianghaiArtPass_FactoryHeroShutter` overlay because the red-brick factory
facade already contains an embedded industrial shutter. Retaining that existing
facade opening removes the duplicate dark door without changing the
Rollershutter Window 03 source record or license. The factory interactive
shutter is framed by five Blender-authored visible objects: reused DCC brick
